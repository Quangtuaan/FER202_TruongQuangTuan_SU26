# API Reference — Week 8: Axios & JSON-Server (CRUD)

All requests have a base URL of `http://localhost:3001` and should send/receive headers as `Content-Type: application/json`.

## Endpoints

### 1. Cars (Supercar Inventory)

#### Get All Cars
- **URL:** `/cars`
- **Method:** `GET`
- **Headers:** None required
- **Success Response:** `200 OK`
  - Array of car objects. Example object structure:
    ```json

      {
        "id": 1,
        "name": "Huracán EVO",
        "brandId": 1,
        "brand": "Lamborghini",

        "engineType": "V10 naturally aspirated",
        "horsepower": 640,
        "torque": 600,
        "topSpeedKmh": 325,
    ```

#### Get Car By ID
- **URL:** `/cars/:id`
- **Method:** `GET`
- **Headers:** None required
- **Success Response:** `200 OK`
  - Body returns the matching car object.

#### Add New Car
- **URL:** `/cars`
- **Method:** `POST`
- **Body Required:** Car fields (excluding `id`, which is auto-generated by the database).
- **Success Response:** `201 Created`
  - Returns the newly created car object.

#### Update Car
- **URL:** `/cars/:id`
- **Method:** `PUT`
- **Body Required:** Updated fields for the car model.
- **Success Response:** `200 OK`
  - Returns the modified car object.

#### Delete Car
- **URL:** `/cars/:id`
- **Method:** `DELETE`
- **Success Response:** `200 OK`
  - Returns confirmation.
