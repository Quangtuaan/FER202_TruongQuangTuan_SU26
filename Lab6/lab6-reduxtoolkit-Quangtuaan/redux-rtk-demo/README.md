# Redux Toolkit Lab 06 (Counter, Todos, Posts)

Dự án này là bài thực hành Redux Toolkit trong ReactJS sử dụng React-Bootstrap.
Gồm 3 tính năng chính:
- **Counter**: Quản lý state đồng bộ đơn giản (tăng, giảm, reset, cộng theo lượng).
- **Todos**: Thao tác với mảng (thêm công việc, đánh dấu hoàn thành, xoá).
- **Posts**: Gọi API bất đồng bộ sử dụng `createAsyncThunk` để lấy dữ liệu bài viết.

## Cách chạy dự án

1. Cài đặt các thư viện (nếu chưa cài):
```bash
npm install
```

2. Chạy ứng dụng trên môi trường phát triển:
```bash
npm run dev
```

3. Build dự án (Production):
```bash
npm run build
```
